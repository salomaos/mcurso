Como deve parecer a edição de uma aula?

Escolha uma das abordagens para sentir o fluxo de edição sem Inputs soltos. Cada exemplo é uma página independente, usa apenas HTML, CSS e JavaScript e não altera o código da aplicação.

01 · VISUAL CANVAS

Editar no próprio documento

A aula aparece como uma página pronta. Clique em um bloco, edite o conteúdo diretamente e organize os elementos sem sair do contexto.
